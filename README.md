# Ashish Rai — Developer Portfolio

My personal portfolio website, presenting my software engineering experience, skills, and selected work. Built with Next.js, React, and TypeScript, with a dark theme and yellow accents.

## Highlights

- Introduction and resume link
- Experience timeline
- Skills covering Phoenix, JavaScript / TypeScript, CSS / Tailwind, PostgreSQL, and Docker
- Development process and PlayBT project showcase
- Contact section and social links
- Scroll reveal effects and animated skill bars

## Project structure

- `app/page.tsx` — portfolio sections and interactions
- `app/globals.css` — styling and responsive layouts
- `app/layout.tsx` — application layout
- `public/` — images and static assets

## Customize

Edit `app/page.tsx` to update experience, skills, project details, and links. Update styles in `app/globals.css` and place images in `public/`.

## Technology

Next.js · React · TypeScript · Tailwind CSS · ESLint

## Run locally

```bash
git clone https://github.com/AshishRai-0197/portfolio.git
cd portfolio
npm ci
npm run dev
```

Open [localhost:3000](http://localhost:3000).

## Available commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm start` | Serve the production build |
| `npm run lint` | Run ESLint |
